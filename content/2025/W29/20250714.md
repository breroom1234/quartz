# Adaptive-Step Graph Meta-Learner for Few-Shot Graph Classification

読んだ論文の詳細まとめ (2025-07-14)


## 論文情報

**URL**: https://arxiv.org/abs/2003.08246
**Conference**: CIKM
**Year**: 2020

### Notes
- Ning Ma, Jiajun Bu, Jieyu Yang, Zhen Zhang, Chengwei Yao, Zhi Yu, Sheng Zhou, Xifeng Yang らの論文
- GNNにおけるメタ学習を提案している論文

背景：
- 既存のグラフメタ学習は，学習の際に，上位クラス(super class) を扱うことでテストクラスにおける新規クラスを効率的にとらえる設計となっている．例えば，画像でいうならば，犬や猫の画像データで学習する際に，哺乳類というsuper class を用いることでテストデータにおいて，牛や馬などの新しいクラスへの対応が容易になるイメージ．
- しかし，現実の設定では train, test データにおいて概念的な overlapが存在しない場合が多い．つまり，super class が存在しない問題がある
- そこで，本研究では，「グラフを構成するサブグラフには共通のものがある」と仮定を置いて手法を設計している．
	- 例えば， triadic closure のようなSNS で頻出するとされている部分グラフがある．それらは，タンパク質でも異なる種類のものでも共通の機能を持つ構造が存在するようなことである．
- 本研究では MAML をもとに手法設計を行うが，単純にグラフに適用する場合において直面する以下の2つの問題を解決するために，強化学習ベースの「コントローラ」という構成要素を使用する．これによって，各タスクを何ステップ学習するのか，学習をどの時点で終了するのかを決定する(early stoppingみたいなイメージ)．

課題定義：
入力：
- 訓練フェーズ：様々なグラフ分類タスクの集まり．各タスクは以下から構成される．
	- サポートセット$\mathcal{D}_{sup}$ 少数のラベル付きグラフのペア．モデルが学習・適応するために使用される．簡単に言えば，各タスクにおける少数訓練データ．
	- クエリセット $\mathcal{D}_{que}$ ：サポートセットで適応したモデルの性能を評価し，モデルの初期パラメータを更新するために使用される．
- テストフェーズ：訓練で一度も見ていない，全く新しいクラスを含むタスク．こちらも，訓練タスクと同様に，サポートセットとクエリセットから構成される．
出力：
- テストタスクのクエリセットに含まれる各グラフのクラスラベル．

N-way K-shot 問題としての定式化．
- N 個の未知のクラスそれぞれについて，各クラスK個のサンプル(サポートセット)が与えられた時に，新しいサンプル(クエリセット) を分類するというタスク．
- データセット $\mathcal{G}=\{(\mathcal{D}_1, y_1), (\mathcal{D}_2, y_2), ..., (\mathcal{D}_n, y_n)\}$ ここで， $\mathcal{G}_i=(\mathcal{V}_i, \mathcal{E}_i, \mathcal{X}_i)$ はグラフ，と$y_i$ はそのラベル．
- メタ学習では，どんな新しいタスクにも素早く対応できる，良い初期パラメータ $\theta$ を学習する．

提案手法：
- 提案手法はGNN-basedなメタ学習機と適応ステップうコントローラの２つの構成要素からなる．
1. GNN-basedなメタ学習器(MAML)：これは，普通に，GraphSAGEのイメージで大丈夫．一応，グラフプーリングを行うために，以下の Attentionを用いてノードの重要さを計算している． $$$S_{i}=\sigma(\tilde{D}_{i}^{-\frac{1}{2}}\tilde{A}_{i}\tilde{D}_{i}^{-\frac{1}{2}}X_{i}\Theta_{att})$$
2. メタ学習器(AS): 適応ステップ数$T$ や学習率などのハイパーパラメータの探索が難しい．なぜなら，元来MAMLは画像のような，周囲のピクセルの数が固定であるデータ構造において提案された技術であるからである．そのため，以下の２つの要素をもとに，コントローラを導入することで，過学習や学習不足などの問題回避に努めている．
	1. グラフ埋め込みの品質．これは，各ノードが周囲の node embedding と差が大きいかという  ANI (Average Node Information) をもとに判断を行う．直感的には，値が大きいほど隣接ノード間でembeddingが適切に離れていることを意味し，いいembeddingが獲得できていると考えられる．$$$ANI_{i}^{l}=\frac{1}{n_{i}^{l}}\sum_{j=1}^{n_i^l}||[(I-(D_{i}^{l})^{-1}A_{i}^{l})H_{i}^{l}]_{j}||_{1}$$
	2. 分類損失：モデルの現在の学習段階における分類精度．
- ステップ数の決定方法：コントローラは上の２つをLSTMににゅうりょくすることで，現在のステップtで適応ステップを中断する確率 $p^{(t)}$ を算出する．
- こちらについて，強化学習を行うために，こちらのステップ数決定を報酬とすることで，コントローラのパラメータを更新．これにより，いいパラメータを得られる学習を効率的に行うことができる．

実験：
- 実験では， COIL-DEL, Graph-R52, Letter-High, TRIANGLES の４つのデータセットを使用
- Graph Kernel, Finetuning, GNNs-Pro, GSM という分類に属する手法と比較を行う．おkれにより，提案手法はほとんど捨てべのデータセットにおいて，性能を上回っている．これにより，super class が存在するという仮定よりも，共通の部分構造を使用するとうい仮定が効果的であったと示されている．


感想：
- 部分構造が大事なのはわかるが，部分構造の形は使用していないのが違和感．あくまで， graphSAGE を使用して，周囲のノードから message passingを行っているだけな気がする．より明示的に部分構造の形が組み込まれているほうが自然な感じがする．
- 部分構造類似性の仮定が妥当ではない気がしている．もう少し妥当な説明が欲しいかもしれニア．
- ANI がいまいちわからないかもしれない．
